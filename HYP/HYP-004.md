# HYP-004 — igniter is the same 3-bar climax as surge; a VWAP-tag bounce on volume is a different event

**Status:** proposed
**Date:** 2026-08-28  **Pod:** igniter
**Instrument:** wall-clock horizons `e4ae3f1`; after-signal neighbourhood `ae685af`. Bar-count / window-only filing numbers are superseded as a verdict.

## Claim

Replacing igniter's entry (`igniterSignal`: three green bars totaling ≥2% with volume ≥3× avg10) with a **VWAP-tag bounce** — prior bar already closed above VWAP, this bar's low tags VWAP, this bar closes green and in the top 30% of its range, volume ≥ `volSurgeMult` × avg10, RSI14 < 75, and close is **not** a 5-bar high — takes +5m forward return from **−6.8 bps (n=20,229) to +51.3 bps** against the `ae685af` after-signal control of **+33.9 bps (1.51×)**, n=3,276, 0.045% of 7,349,065 window bars. +15m: **+101.3 vs after +84.8 (1.19×)**. vs hour at +5m is 1.45×; vs window 6.57×.

## Category

(b) entry signal in `lib/strategies.js` — **igniter only**. New `signalAt`. Do **not** edit `igniterSignal` until surge no longer references it (HYP-003 replaces surge's use; after both land the function can die). Do **not** copy HYP-003's first-expansion bar onto this pod.

Exact conditions at bar `i`:

```
inWindow, i >= 10, atr[i] present
prior close > vwap[i-1]                               // already above — not reclaim's cross
this low <= vwap[i] AND this close > vwap[i]          // tagged and recovered
close > open                                          // green
(close - low) / (high - low) >= 0.7                   // close in top 30% of the bar
v >= volSurgeMult * avg10[i]                          // 3× default
rsi[i] == null || rsi[i] < 75                         // pinned; do not use P.rsiMax (default 85)
close <= max(high of bars[i-5..i-1])                  // not surge's 5-bar break (HYP-003)
stopDist from this bar's low, same helper as today
```

## Mechanism

Igniter uses the same 3-green volume burst as surge, with milder thresholds, so it is the same climax with a smaller dose: 2–3% bursts then return +30 bps, 6%+ bursts return **−31.8**, RSI 80+ return **−33.4**, premarket **−49.9**. Wall-clock, current igniter is **−6.8 vs after +9.6** — still mistimed, less inverted than surge (−27.6 vs after −7.2) because the extra 6,061 fires are milder bursts.

A VWAP-tag bounce is a hold of value on a pullback, not a running high: the name is already above VWAP, dips to it on this bar, and rejects on volume with a strong close. Excluding 5-bar highs keeps this from being HYP-003 in a different hat. It is also not reclaim, which requires the *prior* close to be below VWAP.

## Falsifier

**Written before Builder implements this.** Dies if any of these hold after `igniter.signalAt` is the function above:

1. `node research/edge.js` shows igniter **+5m sig ≤ +5m rnd**.
2. **+15m sig ≤ +15m rnd.** This is a 30-minute quick-strike; a 5-minute pop that is gone by 15 is not usable.
3. Signal count **> 2% of window bars**.
4. Either chronological half of the 144-day library has +5m sig ≤ rnd.
5. Top 5% of +5m winners span **fewer than 100 unique symbol-days**.

#4 and #5 were run on the scratch signal before filing (below) and did not kill it. #1–#3 are for the implemented pod.

## Cost

No change to discovery. Signal count 20,229 → 3,276 (84% fewer minutes). More selective than redgreen (13,870). Live slots will see fewer igniter claims, not more.
